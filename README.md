# 🤖 Projeto Bot de Automação

Um **bot em Python para automação de tarefas repetitivas**, desenvolvido para facilitar a execução de processos rotineiros como leitura de dados, manipulação de informações e execução de fluxos automatizados.

Este projeto utiliza scripts modulares e um arquivo CSV como base de dados para simular operações automatizadas.

## 📖 Sobre o Projeto

O **Projeto Bot de Automação** foi criado com o objetivo de automatizar tarefas que normalmente seriam feitas manualmente, como:

- Processamento de arquivos CSV
- Execução de rotinas automatizadas
- Organização de dados e operações em módulos reutilizáveis

É um projeto ideal para estudos de automação com Python ou como base para bots mais complexos.

---

## ⚙️ Funcionalidades

- 📊 Leitura e manipulação de dados via CSV  
- 🔄 Execução automática de tarefas definidas em script  
- 🧩 Estrutura modular com código principal e funções auxiliares  
- 🚀 Fácil expansão para novos fluxos de automação  

---

## 🧰 Tecnologias Utilizadas

- Python 3.x
- Biblioteca padrão do Python
- Arquivos CSV como base de dados
